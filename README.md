# Anmol Sahu - Portfolio Website

A modern, fully responsive portfolio website showcasing projects, skills, and professional experience.

## Features

✨ **Modern Design**
- Clean and professional UI with gradient colors
- Smooth animations and transitions
- Fully responsive design (mobile, tablet, desktop)
- Dark mode ready

🎯 **Key Sections**
- **Hero Section**: Eye-catching landing area with CTA button
- **About Me**: Personal introduction with statistics
- **Skills**: Categorized technical skills (Frontend, Backend, Tools)
- **Projects**: Showcase of 6 featured projects with descriptions
- **Contact**: Contact form with validation and contact information
- **Navigation**: Sticky navigation bar with smooth scrolling

⚡ **Interactive Elements**
- Mobile hamburger menu
- Smooth scroll navigation
- Form validation
- Notification system
- Intersection observer animations
- Counter animations for statistics
- Typing animation for hero title
- Active section indicator

🛠️ **Technology Stack**
- **HTML5**: Semantic markup
- **CSS3**: Advanced styling with CSS variables and Grid/Flexbox
- **JavaScript**: Vanilla JS for interactivity (no frameworks required)
- **Font Awesome**: Icon library
- **Google Fonts**: Professional typography

## Project Structure

```
├── index.html          # Main HTML file
├── styles.css          # All CSS styles
├── script.js           # JavaScript functionality
└── README.md           # This file
```

## How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/anmolsahu0655/simple-website.git
   cd simple-website
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
     ```bash
     python -m http.server 8000
     # Then visit http://localhost:8000
     ```

## Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    /* ... other variables ... */
}
```

### Content
- Replace project information in the **Projects** section
- Update skills in the **Skills** section
- Modify contact information in the **Contact** section
- Update social media links

### Images
- Replace gradient backgrounds with actual project images
- Update hero section animation or add your own
